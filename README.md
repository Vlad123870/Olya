# Developer Toolkit

Справочник в одном статическом сайте:

- `index.html` — Git Bash и Git
- `visual-studio.html` — Visual Studio для C/C++
- `vscode.html` — Visual Studio Code для Python и C++
- `mathematical-analysis.html` — подробная теория математического анализа
- `linear-algebra.html` — подробная теория аналитической геометрии и линейной алгебры
- `styles.css` — общий дизайн и учебные блоки
- `script.js` — интерактивность Git Bash

## Литература по математике

Матанализ ориентирован на: А. М. Тер-Крикоров, М. И. Шабунин, «Курс математического анализа»; Л. Д. Кудрявцев, А. Д. Кутасов, В. И. Чехлов, М. И. Шабунин, «Сборник задач по математическому анализу».

ЛинАл и аналитическая геометрия ориентированы на Д. В. Беклемишева, «Курс аналитической геометрии и линейной алгебры».

Текст справочников написан заново и не является дословной копией учебников.

## Формулы

Для математических страниц используется MathJax через CDN. При открытии без доступа к интернету математическая разметка может не отрисоваться.
